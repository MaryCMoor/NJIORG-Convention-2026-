# Gallery folder

Add public convention gallery files here to bundle them with the app.

Supported file types:

- `.jpg`
- `.jpeg`
- `.png`
- `.webp`
- `.gif`
- `.mp4`
- `.webm`
- `.ogg`
- `.mov`

Files in this folder are automatically included on the public Photo Gallery page, alongside the Google Sheet `Gallery` rows.

Notes:

- After adding/removing files, rebuild and redeploy the app.
- Use descriptive filenames like `opening-ceremony-group-photo.jpg`; the filename becomes the display title.
- Large videos/photos will increase the app build size and GitHub Pages load time.
